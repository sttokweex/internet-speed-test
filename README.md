# Замер скорости скачивания

Скрипт делает 10 последовательных HTTP-запросов к указанному URL и полностью читает каждый ответ. В конце он выводит среднее время запроса, общий объём данных и среднюю скорость скачивания.

Скорость указана в **Мбит/с** (мегабитах в секунду, 1 Мбит = 1 000 000 бит). Время — в секундах, объём — в байтах и десятичных мегабайтах. Объём считается по данным ответа, которые Node.js передал скрипту.

## Запуск

Нужен Node.js 18 или новее. Дополнительные пакеты не требуются.

```bash
node speed-test.js "https://example.com/image.jpg"
```

Таймаут одного запроса по умолчанию — 30 секунд. Его можно изменить:

```bash
node speed-test.js "https://example.com/image.jpg" --timeout 60
```

Скорость считается по общему объёму ответов и суммарному времени десяти запросов. На результат влияют сервер, сеть и кэширование ресурса.
