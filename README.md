# Замер скорости скачивания

Скрипт делает 10 последовательных запросов к указанному URL, полностью читает каждый ответ и выводит среднее время запроса, общий объём данных и среднюю скорость скачивания.

Для скорости используются **Мбит/с** (мегабиты в секунду, 1 Мбит = 1 000 000 бит). Время указано в секундах, объём — в байтах и десятичных мегабайтах.

## Запуск

Нужен Python 3.9 или новее. Дополнительные пакеты не требуются.

```bash
python3 speed_test.py "https://example.com/image.jpg"
```

Таймаут одного запроса по умолчанию — 30 секунд. Его можно изменить:

```bash
python3 speed_test.py "https://example.com/image.jpg" --timeout 60
```

Скорость считается по общему объёму ответов и времени всех десяти запросов. На результат влияют сервер, сеть и кэширование ресурса.
